# ユーザーズガイド

このガイドだけで、**名寄せが初めてのソフトウェアエンジニア**が、誰にも質問せずにアプリを使えるようになることを目指しています。画面はすべて、実際に操作して撮影したものです。

## 最短の読み順

```
01 基礎と用語(10分) → 02 起動(5分) → 03 デモで体験(15分) → 04 自分のデータで(45分)
                                                                 └→ 困ったら 08 / 仕様を調べたいとき 05・06・07 / 限界は 09
```

| # | 文書 | いつ読むか |
|---|---|---|
| 01 | [名寄せの基礎と用語](01-concepts.md) | 最初に。「ブロッキング」「閾値」など用語が分からないとき |
| 02 | [インストールと起動](02-install-and-start.md) | 動かす前に |
| 03 | [クイックスタート(デモ)](03-quickstart-demo.md) | 合成データで、画面と流れをつかむ |
| 04 | [自分のデータで名寄せする](04-your-own-data.md) | 実際に使うとき。サンプルCSV付き |
| 05 | [画面リファレンス](05-screen-reference.md) | 各画面のボタンや表示の意味を調べるとき |
| 06 | [設定リファレンス](06-config-reference.md) | 標準化・ブロッキング・モデルのJSONを書くとき |
| 07 | [運用・ガバナンス](07-operations.md) | ユーザー追加、個人データ、監査、バックアップ、結果の取り出し |

| 09 | [限界と注意](09-limitations.md) | 本番で使う前に必ず |

## 表記

- ✅ 実際に動かして確認した / 📄 コードや設計書にそう書いてある / ⚠ 推測・未確認
- `PowerShell` のコマンドは、リポジトリの `app` フォルダで実行する想定です(Windows)。macOS / Linux では `python3` に読み替え、パスの区切りを `/` にしてください(⚠ Windows 以外では未検証)。

## サンプルデータ

| ファイル | 内容 |
|---|---|
| [`sample/customers.csv`](sample/customers.csv) | 52件の取引先。同じ会社が「株式会社」「(株)」「㈱」、全角・半角、ハイフンの違いで重複している |
| [`sample/customers-std.json`](sample/customers-std.json) | 標準化の設定 |
| [`sample/customers-pipeline.json`](sample/customers-pipeline.json) | ブロッキングと閾値の設定 |
| [`sample/customers-model.json`](sample/customers-model.json) | 判定モデルの設定 |

人物デモと企業デモ(合成データ)は、アプリに同梱されています(`app/sample_data/`)。
